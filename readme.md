# Tailwind

Los dos archivos ubicados en la raíz del proyecto son esenciales para el funcionamiento de la herramienta:

### tailwind.config.js

Contiene la configuración del framework, tambien sirve para añadir archivos css de terceros a una safelist y permitir modificar las clases originarias de estos desde el archivo input.css

### tailwindcss.exe

Ejecutable que instala archivos como input.css y output.css, ejecuta comandos como actualizar al archivo output.css de forma manual o automática
